# 🖊️ Anotador

Una aplicación web minimalista para escribir sin distracciones, construida con Go.

## Descripción

Anotador es una aplicación web de escritura rápida que simula una hoja en blanco donde puedes escribir libremente. Combina un servidor backend robusto escrito en Go con una interfaz frontend elegante y responsiva. El contenido es efímero: se pierde al cerrar la página. Diseñado para tomar notas rápidas, hacer borradores o simplemente escribir sin la complejidad de un procesador de texto completo.

## Características

- **Servidor backend en Go**: Servidor HTTP con gestión de recursos estáticos eficiente
- **Escritura sin distracciones**: Interfaz limpia, solo tú y tus palabras
- **Tres modos de visualización**:
  - 🌞 **Modo Claro**: Fondo blanco clásico
  - 🌙 **Modo Oscuro**: Para escribir de noche
  - 🌅 **Modo Noche**: Tonos cálidos/amarillentos para descansar la vista
- **Herramientas de formato**: Negrita, cursiva y control de tamaño de fuente
- **Sin persistencia**: Lo que escribes se queda en esa sesión
- **Ajustes discretos**: Panel flotante de configuración que aparece cuando lo necesitas
